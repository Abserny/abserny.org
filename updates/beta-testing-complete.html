Beta Testing Complete

Internal beta testing concluded with all critical issues resolved ahead of the public v1.0 release.

Improvements from testing

  • Double-tap recognition window tuned from 400 ms to 320 ms — reduces false activations
  • Long press threshold set at 700 ms — cleanly separated from double tap timing
  • Swipe threshold set at 60 px with 1.2:1 horizontal ratio — prevents accidental mode changes
  • TTS speech queue improved — new scan interrupts ongoing speech without audible glitch
  • Offline fallback latency reduced from 520 ms to 380 ms median via model quantization
  • Error state recovery time reduced to under 2 seconds
