Documentation Site Launch

Technical Reference Now Available

The official Abserny documentation site is now live at abserny.github.io/abserny.org. It provides complete technical references for the mobile app, the AbserneyVision model, and the planned ASR project.

What's covered

Abserny Mobile

Complete reference for the React Native app — gesture controls with exact thresholds, FSM state diagram, all four detection modes, Gemini and ML Kit pipeline details, bilingual TTS configuration, performance numbers, and installation instructions.

AbserneyVision Model

Architecture, training details, 13 target categories, current validation accuracy (37%), mobile integration notes, and the roadmap toward 80%+ accuracy.

ASR Project

Research motivation, target command vocabulary, architecture candidates, dataset plan, and development roadmap.

Updates feed

All project milestones, release announcements, and development progress documented chronologically.

Design

The documentation site uses the same design language as abserny.com — same dark navy palette, same Archivo typeface, same accent blue, same component patterns — formatted specifically for technical documentation with sticky sidebar navigation, scrollspy, metric grids, and gesture and FSM state tables.
