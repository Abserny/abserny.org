ASR Project Initiated

Custom Arabic Speech Recognition Research Begins

With Abserny v1.0 using a gesture-only interface, we are beginning exploratory research into a custom Arabic speech recognition model as a potential optional future input method.

Why explore ASR at all?

The deliberate choice to use gestures rather than voice in v1.0 eliminates false positives from background speech, TV audio, and ambient noise. However, some users may find situations where gestures are inconvenient. A highly accurate, vocabulary-limited custom model could enable an optional voice mode without the reliability issues of general-purpose recognition.

Research scope

Architecture candidates under evaluation

  • Keyword spotting CNN on MFCC features — smallest, fastest
  • Whisper Tiny fine-tuned on Abserny vocabulary
  • Wav2Vec2 Arabic fine-tuned for command detection

Target vocabulary

Rather than full speech recognition, the model would cover a small set of commands: scan trigger, repeat last, change mode, open settings, and cancel. A vocabulary-limited model is smaller, faster, and has a lower false-positive rate.

Key constraints

  • Must run entirely on-device, no internet required
  • False-positive rate must be extremely low — any spurious trigger disrupts the user
  • Must work in noisy environments typical of daily use
  • Model size must be practical for mid-range Android hardware
